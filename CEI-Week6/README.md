# CEI Week 6 – Apache Spark Architecture & PySpark

## Objective

The objective of this assignment was to understand Apache Spark architecture and perform data processing using PySpark. The assignment also focuses on working with different file formats, DataFrame operations, and Spark optimizations.

---

## Assignment Overview

This assignment demonstrates the implementation of various PySpark operations on the Superstore dataset and the generation of Parquet files and filtered datasets.

---

## Repository Contents

### 1. Jupyter Notebook

**CEI_Week6_PySpark.ipynb**

The notebook contains the implementation of:

- Loading CSV files into Spark DataFrames
- Understanding Spark Architecture
- DataFrame Transformations
- Data Cleaning
- Filtering Records
- Selecting Columns
- Aggregation Operations
- GroupBy Operations
- Sorting
- Creating Parquet Files
- Reading Parquet Files
- Saving Filtered Data
- PySpark Queries

---

### 2. Superstore_Parquet

Contains the Parquet files generated from the Superstore dataset.

This demonstrates:

- Efficient columnar storage
- Faster query execution
- Reduced storage space
