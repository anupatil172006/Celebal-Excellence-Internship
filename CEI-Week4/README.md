# CEI Week 4 – Azure Data Factory Pipeline

## Objective

The objective of this assignment was to understand Azure cloud services and build an end-to-end data pipeline using Azure Storage Account and Azure Data Factory.

## Assignment Tasks

- Create an Azure Resource Group
- Create a Storage Account
- Create a Blob Container
- Upload dataset to Blob Storage
- Create an Azure Data Factory instance
- Configure Linked Services
- Create Source and Sink Datasets
- Build a Data Pipeline
- Validate the pipeline using Debug and Trigger
- Verify successful data movement
